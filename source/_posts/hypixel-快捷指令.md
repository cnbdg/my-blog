# Hypixel 常用命令备忘录 🎮

在 Hypixel 中，大部分操作都可以通过 GUI 完成，但很多聊天频道相关的辅助功能还是使用指令更方便！而且在游戏时，直接敲指令往往比去点 GUI 快得多哦～✨

> **💡 说明：**
> * `< >` 里的参数为**必填**项。
> * `[ ]` 里的参数为**选填**项。
> * 多个别名之间用分号 `;` 隔开。

---

## 📂 社交与聊天 (Social & Chat)

| 命令 | 描述 | 别名 |
| :--- | :--- | :--- |
| `/chat all` | 切换当前聊天频道为**全部** | `/chat a` |
| `/chat party` | 切换当前聊天频道为**组队** | `/chat p` |
| `/chat guild` | 切换当前聊天频道为**公会** | `/chat g` |
| `/chat officer` | 切换当前聊天频道为**公会管理** | `/chat o` |
| `/party chat <msg>` | 在组队频道中发送单条消息 | `/pchat` ; `/pc` |
| `/guild chat <msg>` | 在公会频道中发送单条消息 | `/gchat` ; `/gc` |
| `/guild officerchat <msg>` | 在公会管理频道中发送单条消息 | `/ochat` ; `/oc` |
| `/shout <msg>` | 在分队的游戏中进行**全局喊话**（默认仅队内可见） | 无 |
| `/msg <player> <msg>` | 私信指定玩家（对方若设置权限可能无法收到） | `/tell` ; `/whisper` ; `/w` |
| `/reply <msg>` | 快速回复最近一条收到的私信 | `/r` |
| `/tpa <player> [player]` | 请求与指定玩家传送（需要双方在**同个大厅**） | 无 |
| `/tpa accept [player]` | 接受指定玩家的传送请求 | 无 |
| `/friend list` | 获取好友列表，可直接点击玩家名跨大厅传送 | `/fl` |

---

## 🏛️ 大厅与传送 (Lobby & Teleport)

| 命令 | 描述 | 别名 |
| :--- | :--- | :--- |
| `/lobby [game]` | 进入指定的游戏大厅。`[game]` 参数必须使用缩写。*(例如: `bw` = 起床战争, `sw` = 空岛战争, `a` = 街机游戏)* | `/hub` ; `/leave` ; `/l` |
| `/main` | 返回主大厅 | `/spawn` |
| `/stuck` | 传送回当前大厅的初始位置（不切换大厅），常用于卡地图时 | 无 |

---

## 🛠️ 杂项与实用工具 (Miscellaneous)

| 命令 | 描述 | 别名 |
| :--- | :--- | :--- |
| `/trackpvp` | 在决斗游戏中追踪对方的延迟、失误率等信息 | `/trackcombat` ; `/pvpinfo` |
| `/tip [player] [game]` | 给指定玩家在指定大厅打赏（需对方在线，即使对方未开 Boosters 也行） | 无 |
| `/tip all` | 一键打赏全部开启了 Network Boosters 的玩家 | `/tipall` |
| `/rejoin` | 快速重新加入你刚刚退出的游戏频道或比赛 | `/rej` ; `/back` |
| `/report <player> [type]` | 举报玩家。可以在 `[type]` 直接输入原因而不打开举报书。*(如: `ka` = 杀戮; `fly` = 飞行; `reach` = 长臂猿; `ac` = 连点)* | `/wdr` ; `/watchdogreport` |
| `/fw` | 在自己的头顶燃放烟花（需要相应的 Rank 赞助者权限） | 无 |
| `/getoffmyface` | 让骑在你身上的玩家强制下来 | 无 |

## 🌟 小提示与小技巧 (Tips)

1. **网络小偏方 🔌**
   如果你遇到了资源包无法加载、无法退出 Limbo（虚空大厅）等奇奇怪怪的网络问题，可以尝试先连接到 `stuck.hypixel.net` 然后再换回来，通常就能解决啦！
   
2. **免费白嫖经验与硬币 🪙**
   时不时运行一下 `/tip all`，这不仅对你没有任何损失，反而会让你收获一些额外的经验和硬币，对双方都有好处哦！强烈推荐配合 **AutoTip** 模组使用，省心又省力～
   
3. **大厅移动小妙招 ⚓**
   如果你没有 Rank 权限无法在大厅里飞行，也完全不用担心！在出生地右手边的“大厅探险家”处可以免费领到一个**抓钩小道具**，能让你在建筑之间快速飞跃移动，超级好玩！
   
4. **快捷回复私信 💬**
   `/r` 指令在打本或对局中非常实用。当朋友私信你时，不需要停下操作切频道，直接快速盲敲 `/r k` 就能秒回对方，非常流畅！
